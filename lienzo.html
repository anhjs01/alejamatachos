Guía rápida

Crea a tu manera

Seleccionar: toca o haz clic en una capa para editarla; arrástrala para moverla. Usa los campos de tamaño y posición para ajustes precisos.

Dibujar: elige lápiz, marcador, borrador, formas o línea. En pantalla táctil puedes dibujar con un dedo y usar dos dedos para mover o acercar la vista.

Texto creativo: crea una capa y prueba curvatura negativa o positiva, espaciado, contorno, sombra, onda, arco o perspectiva. La rotación se controla por separado.

Capas: cambia el orden, oculta o bloquea elementos. Deshacer y rehacer también registran las acciones de dibujo.

Guardar: el trabajo se guarda automáticamente en este navegador. Usa “Guardar copia” para conservar versiones con nombre y exporta una imagen cuando termines.

Los proyectos locales se guardan en el navegador de este dispositivo. Exporta un archivo editable JSON para llevar el proyecto a otro dispositivo.
